INSTRUMENT 01 Integrated Gel + Imaging Station Combined electrophoresis box · blue LED transilluminator · Pi camera · timelapse system
DESIGN: TONIGHT → W3 SOURCE: W3–W4 BUILD: W4–W7 FIRST GEL: END W7
Design Tasks
→CAD unified enclosure — gel box cavity at bottom, lightproof imaging hood permanently integrated on top. Hinged lid for gel loading, Pi camera port in the roof, amber filter slide-slot
→Electrode slots in side walls — platinum or stainless wire, banana jack connectors on exterior for bench PSU hookup
→Blue LED transilluminator tray — sits under gel, snap-fits into base. Resin-printed diffuser layer to even illumination
→Print gel combs — 8-tooth and 16-tooth variants, parametric design so you can regenerate for any tooth width
→Pi camera mount — fixed focal length, centered over gel area. No adjustments needed once set
→Python timelapse script — captures frame every N seconds, stitches to GIF or MP4 on completion, saves with run metadata
CAD COMPLETE: END W3 · FIRST GEL: END W7
Source + Build
→Agarose (50g), SYBR Safe (20mL), 50× TAE stock, 1kb ladder, 6× loading dye — all from Amazon or Carolina Bio
→Blue LED transilluminator: $30–50 AliExpress or MiniPCR SafeBlue clone. Or build your own with blue LED strip + diffuser for ~$10
→Amber filter sheet: ~$8. Cut to size for camera port
→Raspberry Pi camera v2 or HQ camera module. Reuse existing Pi Zero 2W if you have it
→Bench PSU for electrophoresis: 300V, 500mA — used lab PSU on eBay ~$30–60. Confirm current limiting before first run
→First run: 1% agarose, 1kb ladder only. Confirm bands. Then run your first real sample
→Push all CAD, scripts, and first gel image to GitHub on day of first successful run
Modifications + Future Additions
⭐ Flagship Mod
Timelapse Band Migration
Pi camera captures frame every 30–60s during a run. Python stitches to MP4. You get a full visual of band separation. Incredibly useful for optimizing run conditions and genuinely cool to share.
Enhancement
Auto Band Detection
OpenCV on Pi: detect band positions in real-time, calculate approximate molecular weight from ladder lane, output a simple band report. Turns your gel imager into a semi-quantitative analyzer.
Enhancement
Auto-Stop by Band Position
Pi monitors band migration in real time. When target band reaches optimal position, Pi triggers a relay to cut power. No more overrunning gels. Genuinely useful QoL feature.
Addition
2D Gel Capability
Design a second electrode axis perpendicular to the first. Rotate gel 90° mid-run for 2D electrophoresis. Serious analytical upgrade, relatively simple mechanical addition.
Addition
Remote Monitoring via Discord
Hook Pi timelapse into your OpenClaw bot — post a frame to Discord every 5 min during a run so you can monitor from anywhere. Gels run overnight while you sleep.
Long Term
Fluorescence Gel Staining Mode
Swap transilluminator for UV if needed, or add a second green LED channel for ethidium-free stains like GelRed. Modular LED tray makes this a print-and-swap upgrade.
INSTRUMENT 02 Microcentrifuge Used/surplus acquisition · validation + optional mods · 6,000–12,000 RPM · 1.5mL tubes
SOURCE: W4–W6 VALIDATE: W7–W8 OPERATIONAL: END W8
Sourcing Strategy
→No design needed — buy used. Search: eBay "microcentrifuge", LabX, BioSurplus, ISU surplus store, Facebook Marketplace science equipment
→Target brands: Labnet Spectrafuge, Benchmark MyFuge, Eppendorf MiniSpin, VWR Galaxy MiniStar
→Minimum spec: accepts 1.5mL + 0.5mL Eppendorf tubes, ≥6,000 RPM. Fixed-angle rotor preferred
→Budget $50–150. University surplus auctions often have these for $20–50
PURCHASE TARGET: W5
Validation + Repair
→Run with balanced water-filled tubes. Check for vibration, noise, wobble — all red flags
→Test spin: colored solution, confirm pellet forms at expected RCF (6,000 × g for 1 min should pellet E. coli easily)
→If brush motor is worn: replacement brushes cost $5–10, YouTube teardown available for most models
→Document rotor type, max RPM, and RCF calculation. Add to Benchling as equipment record
OPERATIONAL: END W8
Modifications + Future Additions
Enhancement
RPM Tachometer Add-On
Stick a reflective strip on the rotor, aim a cheap IR sensor at it, read pulses with a Pi or Arduino. Know your actual RPM instead of trusting a dial. Log every spin session.
Enhancement
Auto-Timed Spin
Relay + timer circuit: set duration, press start, relay cuts power after N seconds. No standing over it watching a clock. Simple PCB or even a mechanical timer plug.
Long Term
Refrigerated Centrifuge (DIY)
Long shot but: Peltier cooling element around the rotor cavity, temperature sensor feedback. Useful for spinning temperature-sensitive proteins. Ambitious secondary project if you're feeling spicy.
Practical
3D-Printed Rotor Adapter
Print adapters for 0.2mL PCR strip tubes, 15mL falcons, or non-standard tube formats your rotor doesn't natively support. Massively extends utility.
INSTRUMENT 03 Fluorimeter PCB 470nm LED driver · Si photodetector · TIA · STM32 · resin cuvette holder · Python dashboard
DESIGN: W3–W6 SOURCE: W7–W8 BUILD: W8–W11 VALIDATED: END W11
Design Tasks (KiCad)
→LED driver: constant-current circuit for 470nm LED. LM317 or AL8805 LED driver IC. Low noise — this drives your excitation source
→Photodetector: silicon photodiode (SFH2430 or similar) → transimpedance amplifier. OPA2134 or AD8627 for low noise, low bias current. Selectable feedback resistors for gain ranging
→ADC: 16-bit ADS1115 or STM32 internal 12-bit ADC. USB-serial out via STM32 CDC
→CAD: resin cuvette holder with 90° geometry (excitation from below, emission detected from side), 520nm bandpass filter slot, lightproof snap-fit lid
→PCB layout, design rule check, export Gerbers to JLCPCB ($10 for 5 boards, 1-week turnaround)
GERBERS TO JLCPCB: END W6
Build + Validate
→Assemble PCB: power rails first, LED driver second, TIA last. Scope every stage with a multimeter and logic analyzer before moving on
→First light test: confirm LED driving at constant current, photodiode responding to ambient changes
→Fluorescein validation: make 6-point serial dilution in PBS, read each. Confirm linear R² > 0.99
→FAM validation: if you have FAM-BHQ oligo already, confirm you can detect FAM signal after reporter cleavage simulation (just free FAM dye)
→Python dashboard: real-time plot, calibration curve fit, CSV export, concentration readout from standard curve
LINEAR CALIBRATION CURVE: END W11
Modifications + Future Additions
⭐ High Value
Multi-Channel / Multi-Wavelength
Add a second LED (e.g. 530nm for SYBR Green, or 590nm for Texas Red) with a filter wheel or flip-mount. Now you can read multiple fluorophores without swapping hardware. Critical for multiplex CRISPR assays.
⭐ High Value
Kinetic Mode
Read fluorescence continuously over time at 37°C (add a small Peltier heater to the cuvette holder). Now you can watch Cas12a trans-cleavage happen in real time — a proper kinetic fluorescence assay. This is how the capstone biology actually runs.
Enhancement
Plate Reader Mode
Design a 96-well or 8-strip adapter that positions each well over the detector in sequence via a stepper-driven XY stage. Suddenly you have a basic plate reader for ~$50 more in parts.
Enhancement
Lock-in Amplifier Firmware
Modulate the LED at a known frequency, use STM32 to demodulate the photodetector signal at that frequency only. Dramatically improves SNR — filters out ambient light and 1/f noise without any additional hardware.
Addition
Absorbance Mode (Spectrophotometer)
Place LED and detector in-line instead of 90°. Now you can read OD600 for bacterial culture density — useful for E. coli growth curves in your home BSL-1 work.
Long Term
Chip-Integrated Optics
Move the LED and photodetector into the microfluidic chip carrier itself, so the chip slots in and optical alignment is automatic. Eliminates manual alignment every run — key for the capstone integration.
INSTRUMENT 04 Potentiostat PCB Voltage DAC · TIA current sense · STM32 · CV/DPV waveforms · 3-electrode connector · Python CV plotter
DESIGN: W5–W8 SOURCE: W9–W10 BUILD: W10–W13 VALIDATED CV: END W13
Design Tasks (KiCad)
→Study CheapStat and Rodeostat open-source designs first — understand the control loop before designing your own variation
→DAC (MCP4922 or DAC8552) sets working electrode potential via a voltage follower op-amp. ±2V range covers most biosensor work
→TIA on counter electrode measures current response. Same low-noise op-amp philosophy as fluorimeter TIA — share component library
→STM32 generates CV/DPV/EIS waveforms, streams voltage+current pairs over USB-serial at 1kHz sample rate
→3-electrode header: working, reference (Ag/AgCl), counter. Design for standard screen-printed gold electrode chips (SPE)
→Dual-supply rail (±5V from USB via charge pump or external wall wart). Shield layout carefully — this is an analog instrument
GERBERS TO JLCPCB: END W8
Build + Validate
→Bring up with a known resistor load first — confirm DAC output and current measurement agree with Ohm's law before any electrochemistry
→First CV: ferri/ferrocyanide (5mM K₃[Fe(CN)₆] in 0.1M KCl). Textbook reversible redox couple — clean duck-bill CV shape confirms instrument works
→Characterize: scan rate dependence of peak current (Randles-Ševčík), confirm linear relationship. This is your validation data
→Python: CV plotter, DPV plotter, peak detection, data export. Clean UI — this is a Marc Lab product
→Document fully with validation plots in Benchling and GitHub README
VALIDATED WITH FERRI/FERROCYANIDE: END W13
Modifications + Future Additions
⭐ Capstone Link
Electrochemical CRISPR Readout
Functionalize a gold electrode with the FAM-BHQ ssDNA reporter. When Cas12a cleaves it, the electrode surface chemistry changes measurably. Secondary readout for the capstone that doesn't rely on optics — redundant validation is scientifically stronger.
Enhancement
EIS Mode (Impedance Spectroscopy)
Add a sine wave generator and lock-in detection in firmware. Electrochemical impedance spectroscopy unlocks biosensor surface characterization — confirm antibody or aptamer binding on electrode surface without optical labels.
Enhancement
Multiplex Electrode Array
Design a multiplexer (CD4051 or similar) in front of the TIA to switch between 4–8 electrodes sequentially. Now you can run a cytokine panel on a single chip — one potentiostat, multiple analytes.
Addition
PCB Electrode Fabrication
Instead of buying screen-printed electrodes, design your own gold or carbon electrode patterns directly in KiCad and have JLCPCB fab them. Dramatically reduces per-experiment cost from ~$3 to cents per chip.
Long Term
Wearable Patch Version
Miniaturize to flexible PCB format with BLE output. Skin-conformal electrode array, sweat or ISF sampling. Now it's a wearable biosensor platform — entirely different product direction if you want to go there.
INSTRUMENT 05 qPCR Thermocycler Peltier thermal block · PID firmware · FAM detection channel · STM32 · 8-tube strip format
DESIGN: W6–W10 SOURCE: W11–W12 BUILD: W13 → EARLY FALL FIRST PCR: EARLY FALL
Design Tasks (KiCad + CAD)
→This is the most complex build. Allocate 5 weeks of design time — it's earned
→Peltier driver: H-bridge (DRV8701 or discrete MOSFETs), current-limited, bidirectional — allows heating AND cooling. This is what enables fast ramp rates
→Thermal block: aluminum block with 8-tube strip cavity machined or sourced, NTC thermistor embedded, Peltier sandwich, heatsink on cold side with small fan
→STM32 PID: dual-loop (heating/cooling), ramp rate target, overshoot compensation. Tune for ±0.5°C steady-state
→FAM channel: reuse fluorimeter TIA design, LED fires from below each cycle during extension — share component library
→Heated lid: resistive heater + second thermistor, prevents condensation, holds at 105°C during cycling
GERBERS: END W10 · COMPONENTS ORDERED: W12
Build + Validate (W13 → Fall)
→Bring up power stage first — Peltier driver is the highest risk. Confirm H-bridge switching before attaching Peltier
→PID tuning: log temperature vs time at multiple setpoints. Tune Kp/Ki/Kd until ramp rates hit 2–3°C/s and overshoot is <1°C
→First PCR: lambda DNA + universal primers, 30 cycles, standard protocol. Run product on your gel rig — band at expected size = success
→qPCR validation: SYBR Green + dilution series. Confirm Ct values shift by ~3.3 per 10× dilution (expected for PCR efficiency ~100%)
→Python: cycle program editor, real-time temp + fluorescence plot, Ct calling algorithm, efficiency curve
FIRST SUCCESSFUL PCR: EARLY FALL SEMESTER
Modifications + Future Additions
⭐ Capstone Link
Isothermal Amplification Mode
Add a single-temperature hold mode (37°C or 42°C) for LAMP or RPA upstream of Cas12a detection. Amplify target DNA isothermally, then feed directly into CRISPR assay. Dramatically lowers limit of detection for the capstone system.
⭐ High Value
Multiplex Fluorescence (HEX + FAM)
Add a second LED (530nm) + second photodetector channel with HEX filter. Now run multiplexed qPCR — target + internal control in the same tube. More scientifically rigorous, more publishable.
Enhancement
Gradient Block
Machine the aluminum block with a slight thermal gradient across the 8 tubes using two independent Peltiers. Run annealing temperature optimization in a single reaction — the classic gradient PCR trick, built into your instrument.
Enhancement
AAV Titer Mode
Implement a dedicated protocol template for AAV genome titer: ITR-targeting primers, absolute quantification from standard curve, formatted QC report output. Turns this into a gene therapy QC instrument — exactly what project 9 from the original list envisioned.
Addition
Digital PCR Module
Long shot: design a microfluidic chip that partitions sample into thousands of nanoliter droplets, run PCR on chip, count positive droplets with the fluorescence channel. That's DIY ddPCR — currently no open-source instrument exists at any price.
Long Term
96-Well Upgrade
Design a larger thermal block for standard 96-well plates. Requires a bigger Peltier array and more thermal mass, but the PCB and firmware architecture scales directly. Turns Marc Lab into a real high-throughput qPCR platform.
INSTRUMENT 06 Microfluidic Chip Platform Resin-printed reaction chamber · optical window · biocompatibility characterization · snap-fit carrier
DESIGN: W9–W13 PRINT + TEST: W14 → FALL BIO-COMPATIBLE V1: EARLY FALL
Design Tasks
→Literature first: read 3–5 papers on resin-printed microfluidics. Know your printer's channel resolution limits before designing anything
→V1 geometry: simple. One inlet, one reaction chamber (50–200µL volume), one optical window zone, one vent. No active mixing — passive diffusion only
→Optical window: thin resin membrane or open-top design that aligns precisely with fluorimeter beam path
→Chip carrier: snap-fit resin enclosure that holds chip, aligns to fluorimeter, and maintains lightproofing. Design so chips are swappable in 5 seconds
→Biocompatibility protocol: wash in IPA, cure under UV, soak in PBS for 24h, read fluorescence of soak buffer on fluorimeter. Leaching = signal above baseline. Iterate until clean
DESIGN V1 COMPLETE: END W13
Print + Test (W14 → Fall)
→Print V1. Wash 3× IPA, cure 60min UV. Measure channel dimensions with calipers or macro lens photo
→Leak test: fill with water + food coloring, apply pressure with syringe. Note any leaks or delamination
→Biocompatibility: soak buffer absorbance/fluorescence over 2h at 37°C. If signal elevated, extend wash protocol or switch resin
→Flow characterization: syringe pump (or gravity flow), measure dead volume, fill time, mixing uniformity with colored dye
→Expect 2–3 print iterations. That's normal. Document every version with photos and test data in Benchling
BIOCOMPATIBLE + LEAK-FREE V: EARLY FALL
Modifications + Future Additions
⭐ Capstone Core
Integrated Heating for Incubation
Embed a resistive heater trace in the chip carrier PCB, thermistor feedback, hold at 37°C during Cas12a incubation. No external heat block needed — the chip carrier is also the incubator.
Enhancement
Herringbone Micromixer
V2 chip geometry: add herringbone ridges in the channel ceiling to passively mix laminar flow. Critical if you ever want to run two-component mixing on-chip (e.g. Cas12a + sample). Resin printing can achieve this at ~100µm feature sizes.
Enhancement
Droplet Generation
T-junction or flow-focusing geometry for water-in-oil droplet formation. Each droplet is an individual reaction. That's the foundation of digital PCR and droplet CRISPR assays. A V3 chip geometry, but the printer can do it.
Enhancement
Surface Functionalization
Coat channel walls with PDMS-compatible silane chemistry or protein-blocking agent (BSA, PEG-silane) to reduce non-specific adsorption of Cas12a or reporter. This is real biomaterials surface science — publishable characterization data.
Addition
LNP Formation Chip
Design a herringbone staggered mixer for lipid + aqueous stream mixing — the LNP microfluidic former from the original project list. Same chip platform, different geometry. Marc Lab ships two chip variants from one resin printer.
Long Term
Valve Integration
Pneumatic or Braille-pin valves for active flow control — compartmentalize assay steps on-chip (sample prep → amplification → detection). True lab-on-chip. Ambitious but within reach of resin printing at this feature scale.
The Capstone
AI-DIRECTED OPEN-SOURCE
CRISPR OPTIMIZATION PLATFORM
An autonomous experimental loop running entirely on Marc Lab hardware. The fluorimeter reads Cas12a trans-cleavage assays in real time. A Python/Claude agent analyzes each result and proposes the next crRNA variant or condition via Bayesian optimization. The loop runs, learns, and converges — on instruments you designed, on a home bench, for under $600 total. Nothing like this exists at this accessibility level.
Fluorimeter
Primary readout. Kinetic FAM signal during Cas12a trans-cleavage incubation at 37°C
Thermocycler
Upstream sample prep + isothermal amplification (LAMP/RPA) to boost target copy number
Potentiostat
Secondary electrochemical readout. Redundant validation of detection signal
Microfluidic Chip
Reaction vessel for chip-format assay. Integrated heater in carrier for incubation
Agent Loop
Claude/Hermes Bayesian optimizer proposes next experiment. Logs all runs. Built on OpenClaw infrastructure
Sequencing
Plasmidsaurus confirms top crRNA candidates externally. Keeps biology honest without ISU access
